# PLUCK 심볼

## 콘셉트

PLUCK = "본질을 뽑아 제품으로". 심볼은 소문자 **p** 하나와, 그 p 의 속(카운터)에서 **뽑혀 나온 알맹이(seed)** 하나로 이루어진다.

- p 의 동그란 구멍과 오른쪽 위의 점은 **같은 지름**이다. 구멍에 있던 조각을 집어 올린 것처럼 읽히게 하려는 의도다. 뽑아낸 본질이 점이고, 남은 p 가 그걸 담아낸 제품이다.
- 획은 하나의 굵기(알약 막대 + 링)로만 만든다. 그래서 평면에서는 굵고 단순하게, 3D 에서는 캡슐 + 토러스 + 구로 그대로 세워진다(lib/pluck-symbol-3d.ts).
- Lusion 의 십자/파이프 형태와 겹치지 않도록 글자 기반으로 만들었다. 3D 히어로에서는 p 와, p 에서 떼어낸 두 조각(링, 알약)이 함께 떠다닌다.

## 구성 (120 x 120 그리드)

| 요소 | 값 |
| --- | --- |
| 획 굵기 | 26 (반지름 13) |
| 막대(stem) | 중심선 x=24, y 20→100, 양끝 반원 |
| 링(bowl) | 중심 (48, 44), 중심선 반지름 24 → 바깥 37, 구멍 11 |
| 알맹이(seed) | 반지름 11, 중심 (94, 12) — 링 중심에서 -35° 방향 |
| 맞춤 | 링 왼쪽 바깥선 = 막대 왼쪽선, 구멍은 막대 안쪽선에 접한다 |

원본 좌표는 `docs/brand/symbol-svg.js` 에 있다. 이 스크립트로 SVG 세 개를 다시 만들 수 있다. 3D 렌더는 `docs/brand/render-3d.js` 로 만든다.

## 파일 (public/brand/)

| 파일 | 용도 |
| --- | --- |
| `pluck-symbol.svg` | 기본 2색(블루 p + 잉크 점), 밝은 바탕 |

## 색

| 이름 | HEX | 쓰는 곳 |
| --- | --- | --- |
| PLUCK 블루 | `#335aeb` | p 본체 기본색 |
| 잉크 | `#202523` | 밝은 바탕의 점, 1색 버전 |
| 오프화이트 | `#f4f4ef` | 어두운 바탕의 p 또는 점 |
| 라임 | `#d9eba7` | 블루나 잉크 바탕 위의 점(악센트) |

허용 조합은 다음과 같다. 블루 p + 잉크 점(밝은 바탕), 오프화이트 p + 라임 점(잉크 바탕), 오프화이트 p + 잉크 점(블루 바탕), 1색(아무 바탕). 라임은 밝은 바탕에서 대비가 부족하므로 흰 티셔츠 위에는 쓰지 않는다.

## 여백과 최소 크기

- 여백: 심볼 둘레에 **알맹이 지름(22 그리드 단위) 이상**을 비운다. 락업도 같은 기준이다.
- 최소 크기: 화면 16px(파비콘). 이 크기에서 점은 약 3px 로 남는다(미리보기로 확인). 인쇄 최소 크기는 6mm.
- 점은 떼지 않는다. 점 없는 p 는 PLUCK 심볼이 아니다. 점의 위치와 크기, p 와 점 사이 간격도 바꾸지 않는다.

## 머천다이즈 메모

- **자수**: 획이 굵고 디테일이 없어서 30mm 이상이면 1색 자수가 가능하다. 구멍(심볼 높이의 약 20%)이 메워지지 않도록 30mm 미만에서는 실크 인쇄를 권한다.
- **실크/DTF**: 2색 인쇄라면 블루 `#335aeb` 의 별색은 시안 출력으로 맞춰서 정한다(화면 HEX 를 그대로 쓰지 않는다). 잉크 티셔츠에는 오프화이트 p + 라임 점 조합.
- **큰 그래픽**: 등판이나 토트백 전면에는 `pluck-symbol-3d.png` 를 크게 써도 된다. 단 DTF 전용이고, 투명 PNG 그대로 쓴다.
- **패턴**: 작은 심볼을 회전 없이 반복한다. 히어로처럼 기울이고 섞는 연출은 웹 모션에만 쓴다.
- 락업의 `®` 는 현재 사이트 워드마크를 그대로 따른 것이다. 상표 등록 상태를 확인한 뒤 굿즈에 넣을지 정한다.
